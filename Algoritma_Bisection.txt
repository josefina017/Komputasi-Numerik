SOAL YANG SAYA PAKAI:

PENGERTIAN SINGKAT VERSI SAYA:
Metode Bisection itu seperti kita menebak angka dengan cara
membagi dua terus-menerus.
Kita punya dua batas, batas kiri (a) dan batas kanan (b).
Kalau di kiri hasilnya negatif dan di kanan hasilnya positif,
berarti akarnya ada di tengah-tengahnya.
Terus kita bagi dua, cek lagi, bagi dua lagi, sampai ketemu
angka yang sangat dekat dengan akar sebenarnya.

LANGKAH-LANGKAH ALGORITMA SAYA:

1. MULAI
   Saya mulai program dan tampilkan nama dan NIM saya.

2. TENTUKAN FUNGSI
   Saya tentukan fungsi f(x) = x^2 - 4.

3. TENTUKAN BATAS AWAL
   Saya pilih a = 1 dan b = 3.
   Karena f(1) = -3 (negatif) dan f(3) = 5 (positif).
   Karena tandanya beda, berarti akar pasti ada di antara 1 dan 3.

4. TENTUKAN TOLERANSI DAN MAKSIMAL ITERASI
   Saya pakai toleransi = 0.001
   Maksimal iterasi saya buat 20 kali.

5. PROSES ITERASI (ULANGI SAMPAI KETEMU)
   a. Hitung titik tengah: c = (a + b) / 2
   b. Hitung f(c)
   c. Kalau f(c) = 0, berarti c adalah akarnya, berhenti.
   d. Kalau f(a) * f(c) < 0, berarti akar ada di kiri,
      jadi saya ganti b = c
   e. Kalau tidak, berarti akar ada di kanan,
      jadi saya ganti a = c
   f. Cek apakah (b - a) sudah lebih kecil dari toleransi.
      Kalau sudah, berhenti. Kalau belum, ulangi dari langkah a.

6. TAMPILKAN HASIL
   Saya tampilkan nilai akar yang ketemu, yaitu nilai c terakhir.
   Saya tampilkan juga berapa kali iterasi yang dilakukan.

7. CEK KEBENARAN
   Saya masukkan nilai akar itu ke fungsi awal.
   Kalau f(akar) mendekati 0, berarti jawaban saya BENAR.

8. SELESAI
